## 技术说明

- 纯静态单文件 HTML（内嵌 CSS/JS），无构建依赖，GitHub Pages 直接托管
- 域名：`cantyouknow.com`（CNAME 绑定 GitHub Pages）
- 天气数据：[Open-Meteo](https://open-meteo.com/)；寄语数据：[一言 hitokoto.cn](https://v1.hitokoto.cn/)，均有本地兜底

## 报告更新约定

- 康波报告按月更新（每月1日），最新版始终在 `康波周期可视化报告.html`，旧版本以 `_YYYY年M月.html` 归档，报告文末与首页均提供历史版本入口
- 每期新版包含对上期预测的复盘（对/错/原因），保留完整决策痕迹
